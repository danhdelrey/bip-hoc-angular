Tình huống nào dùng gì?

State của component/servicesignal + computed (thay BehaviorSubject)
Giá trị suy ra từ nhiều statecomputed (không glitch như combineLatest)
State phụ thuộc nhưng sửa đượclinkedSignal
Đồng bộ ra ngoài (localStorage, log, thư viện DOM)effect; không dùng effect để copy signal sang signal
Tải dữ liệu theo tham sốrxResource / httpResource, hoặc toObservable → switchMap → toSignal
Ô tìm kiếmdebounceTime + distinctUntilChanged + switchMap
Nút Lưu, Submit, Đăng nhậpexhaustMap
Hàng đợi theo thứ tự / nhiều việc song songconcatMap / mergeMap, forkJoin
Lỗi mạng tạm thờiretry({{ '{' }} count, delay {{ '}' }})
Một request lỗi không làm chết streamcatchError bên trong switchMap
Cache kết quả dùng chungshareReplay(1)
Polling đến khi xongtimer(0, ms) + switchMap + takeWhile(…, true)
Tích luỹ (tải thêm, giỏ hàng)scan hoặc signal.update
Subscribe thủ công trong componenttakeUntilDestroyed(), hoặc dùng toSignal cho khỏi subscribe
Tắt loading dù thành công/lỗi/huỷfinalize
